Decision Transformer, Hopper-v5

Each video is one deterministic episode of the same trained Decision Transformer (seed 0, trained on Minari mujoco/hopper/medium-v0), differing only in the return-to-go it is told to achieve. The slider picks the target. Videos are pre-rendered; nothing runs in your browser.

One episode per target, fixed env seed 12345, not selected. A single episode is an anecdote; the repository README has the 3-seed x 10-episode numbers. Normalized score = 100 (return - random) / (expert - random) with the D4RL Hopper reference returns (-20.27, 3234.3); the Minari medium data already scores around 87 by this scale, so values above 100 are possible. The model is also exported to hopper_dt.onnx (fixed context of 20 steps; PyTorch/onnxruntime outputs agree to the tolerance stated in the README).
